Under the hood

Good bones, rebuilt plumbing

The original had the right vision and heavy execution. Alice keeps the vision and guts the engine room — the result is, in testing, lightning fast.

Engine

FIFO queue with backpressure

Image generations queue in order and never get dropped. No silent failures, no lost work.

Engine

Dual-engine VRAM arbitration

Text and image engines share 8 GB gracefully. Image weights park in RAM and stream to VRAM only during generation. Live health monitoring in the UI.

Engine

Local-first, always

Your models, worlds, and characters live on your machine. KoboldCpp managed in-app. No cloud required, no account needed.

Interface

Three detail levels

Simple, Balanced, Advanced — with progressive disclosure both ways. A mode is a default, never a cage.

Interface

Main Character board

Collapsible sections: Kardashev scale (with live gear checks), personality, appearance, voice, world. AI writes NPCs — you author the MC.

Interface

Plain-English glossary

MC, NPC, User — defined in-app, in words a new user actually understands. No jargon walls.

Content zones

Your boundaries, your definitions

Three zones at account creation (18+ gated where appropriate):

  • Safe Commons — full SFW guardrails
  • NSFW — light guardrails
  • Dead Dove — no app-added rails; you negotiate hard / soft / yellow limits plus Allow / Don't-allow lists
Safety floor

One invariant, total flexibility inside it

A single non-negotiable floor — nothing enables sexual content involving minors, in any zone. Everything else is yours to define.

Design

Flat, fast theme

Deep teal, white, pink/blue accents. No runtime font fetching, no expensive per-card shadows. A skin should be colors, not compute.

Get it

One file, every distro

Rabbit Hole ships as a Flatpak — a single universal installer for all of Linux. A .deb is available for Debian/Ubuntu-family systems.

📦 Flatpak Recommended

Universal Linux installer. No root needed. Works on Debian, Fedora, Arch, openSUSE — all of them.

flatpak install --user RabbitHole.flatpak
flatpak run io.github.scarlet1987.RabbitHole

Or grab it from the releases page. Flathub listing Coming soon

🐧 .deb Debian / Ubuntu

For Pop!_OS, Ubuntu, Mint, Debian. Installs to /opt, launcher in your app menu.

sudo apt install ./front-porch-ai_1.5.0-alice5_amd64.deb
front-porch-ai

Uninstalls cleanly with sudo apt remove front-porch-ai. Your data in ~/.local/share is preserved unless you clear it.

Requirements

What you need

🖥️ Linux x86_64

Any modern distro (Flatpak) or Debian-family (.deb).

🎮 8 GB VRAM

Recommended. The engine layer enforces a budget so it stays smooth on ordinary hardware.

🧠 KoboldCpp

Backend for text generation — managed in-app, no separate setup.

🎨 Image backend (optional)

A1111, Forge, or ComfyUI running locally for image generation.
